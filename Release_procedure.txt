PCMan Lite release procedure
============================

1. Update the version values in Version_Set_Lite.bat.
2. Run Version_PreBuildEvent_Lite.bat to regenerate Lite/Version.h.
3. Rebuild PCMan.sln using Release|Win32.
4. Run Scripts/AfterBuild.ps1 to create the Lite archive and installer.

The final PCMan Combo source is archived by the Git tag combo-final and is no
longer built or released from the main development branch.
