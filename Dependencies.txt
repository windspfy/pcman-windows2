這份文件說明開發和釋出的需求

- [開發] Visual Studio 2026 (Community 即可)

需安裝「使用 C++ 的桌面開發」、MSVC v143、x86 MFC、Windows 11 SDK
10.0.26100.0 與 vcpkg。

- [開發] cpprestsdk 2.10.19 (須包含 websockets feature)

不需再手動執行全域 `vcpkg install`。專案根目錄的 vcpkg manifest 會在
首次建置時自動還原相依套件。

由於 cpprestsdk 已封存，且新版 vcpkg 已移除其 port，本專案使用
vcpkg-overlay-ports/cpprestsdk 提供 WebSocket 相依宣告及新版 MSVC 相容修補。

- [釋出] Microsoft Visual C++ Redistributable for Visual Studio 2015-2022 (x86)

可至 https://www.visualstudio.com/downloads/ 的 Other Tools and Frameworks 區域下載.
